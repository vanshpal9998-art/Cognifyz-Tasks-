About the Internship

This repository contains my completed tasks and projects as part of the Data Science Internship at Cognifyz Technologies.

The internship provided practical experience in data analysis, data preprocessing, exploratory data analysis (EDA), geospatial analysis, and feature engineering using Python.

- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Data Visualization
- Exploratory Data Analysis (EDA)
